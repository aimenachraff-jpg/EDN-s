\chapter{Software Artifacts}

\section{Python Application}
The inference application is available at \texttt{sr\_app.py} with a dark-themed GUI supporting:
\begin{itemize}
    \item Drag-and-drop input GeoTIFF loading
    \item Threaded SR processing (queue-based, non-blocking)
    \item Three-panel display (Original / EDSR / EDSR+)
    \item Hallucination detection integrated into status bar
    \item Keyboard shortcuts (\texttt{Ctrl+O}, \texttt{Ctrl+S}, \texttt{Esc}, \texttt{R})
    \item CLI mode: \texttt{python sr\_app.py input.tif output.tif}
\end{itemize}
Double-click launcher: \texttt{run\_sr\_app.bat}.

\chapter{Reproducibility Checklist}

All experiments are reproducible:
\begin{enumerate}
    \item \textbf{Data:} Download from Kaggle \texttt{aymencharafedn/s2-tiles-trainval} (v18)
    \item \textbf{Model:} Load checkpoint \texttt{experiments/checkpoints/edsr\_small\_phase5\_best.pt}
    \item \textbf{Metrics:} Run \texttt{scripts/verify\_kaggle\_files.py} to confirm tile counts match
    \item \textbf{Hallucination:} Run \texttt{scripts/phase6\_hallucination.py} on test tiles
    \item \textbf{Statistics:} Run \texttt{scripts/phase8\_statistical\_analysis.py}
    \item \textbf{GUI App:} Run \texttt{python sr\_app.py} or double-click \texttt{run\_sr\_app.bat}
\end{enumerate}

Seed: 42. Hardware: Kaggle 2$\times$ T4 16~GB; local CPU (Intel Iris Xe). Python 3.10.11, PyTorch 2.11.0+cu130 (Kaggle), 2.3.0 (local).

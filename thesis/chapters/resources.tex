\section{Sentinel-2 Dataset}

The primary dataset is Sentinel-2 Level-2A (Surface Reflectance), acquired from the \href{https://planetarycomputer.microsoft.com}{Microsoft Planetary Computer} STAC API. This serves as a spectral proxy for ALSAT-2B multi-spectral imagery, sharing similar blue-green-red-NIR band positions.

\subsection*{Download URL}
\begin{itemize}
    \item STAC API: \url{https://planetarycomputer.microsoft.com/api/stac/v1/}
    \item Query parameters: collection = \texttt{sentinel-2-l2a}, spatial bbox per AOI, temporal range 2020--2022
\end{itemize}

\subsection*{Metadata}
\begin{itemize}
    \item License: Copernicus / Sentinel-2 Data, CC BY 4.0
    \item Attribution: ``Sentinel-2 Level-2A surface reflectance. European Space Agency.''
    \item Processing level: L2A (surface reflectance, values in [0, 1])
    \item Bands used: B2 (Blue 490 nm), B3 (Green 560 nm), B4 (Red 665 nm), B8 (NIR 842 nm)
    \item Native resolution: 10 m
    \item Actual CRS in download: EPSG:4326 (reprojected from native UTM)
\end{itemize}

\subsection*{Acquisition Script}
\texttt{scripts/sentinel2\_full.py} and \texttt{scripts/sentinel2\_pilot.py}.
Seed: 42. Rejected granule: \texttt{31SDB\_20201223} (degenerate) -- recorded in \texttt{data/metadata/sentinel2/rejected\_items.json}.

\section{Simulated ALSAT-2B Dataset on Kaggle}

The simulated $\times$4 train+val tiles (ALSAT-2B proxy) are uploaded to Kaggle for GPU training.

\begin{itemize}
    \item Dataset slug: \texttt{aymencharafedn/s2-tiles-trainval}
    \item Current version: v18, 78.16 GB, 10,697 files
    \item View/download: \url{https://www.kaggle.com/datasets/aymencharafedn/s2-tiles-trainval}
    \item Contents: 10,680 TIFs (4-band float32, 10m, 1024$\times$1024) across 8 AOIs + tile-index CSVs + normalization stats
\end{itemize}

\textbf{Test tiles} (4,068) were intentionally kept local (not uploaded) to support Phase 6 hallucination evaluation.

\subsection{Infrastructure Notes}
\begin{itemize}
    \item Kaggle input layout: \texttt{/kaggle/input/datasets/<owner>/<slug>} (not \texttt{/kaggle/input/<slug>})
    \item \texttt{glob(..., recursive=True)} unreliable on Kaggle mount (204/10,680 tifs); use \texttt{os.walk}
    \item Dataset attachment in kernel-metadata uses \texttt{dataset\_sources} (not \texttt{dataset\_data})
    \item PyTorch 2.6: \texttt{torch.load} default \texttt{weights\_only=True} breaks checkpoint loading; use \texttt{weights\_only=False} for trusted sources
    \item Training run ``error'' status was only the eval step (torch.load incompatibility); training itself completed fully
\end{itemize}
